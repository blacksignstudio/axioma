### 01 — Entry Without Return (Expanded Mode)

A way in

No shift.

you’ve crossed.

This is not capture.  
It is structure  
configured to deny reversal.

The door is not locked.  
It is no longer there.

AXIOMA builds the entrance  
to function once.  
To convert direction  
into enclosure.

You are not imprisoned.  
You are suspended  
within your own motion  
folded into architecture.

There is no return path.  
Because return  
was never part of the pattern.

You do not look back.  
There is no back.

There is only continuation  
of a movement  
that no longer leads anywhere  
but further inward.
